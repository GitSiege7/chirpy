# Chirpy
### Description
Chirpy is a backend RESTful API designed to query a database of twitter-like `Chirps` and `Users`. It supports all CRUD operations, user authentication, and session management.

#### Database
PostgreSQL is used as it is an industry standard and highly utilized at the production level.

#### SQLC
SQLC is used to convert SQL queries into Go code, allowing the Go backend to query the PostgreSQL database.

#### HTTP Server
Golang's HTTP Server is used to serve requests for its compact and simplistic, yet highly efficient capabilities.

#### Boot.dev
This is a guided project from Boot.dev, an online backend coding course; however, I designed, implemented, and wrote all of the code myself with very little help beyond broad direction and I have a strong understanding of its functionality.
